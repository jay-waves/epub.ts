# 类型与代码质量复核

本轮沿设置接口、书籍打开 → 注释恢复 → 编辑 → 搜索 → 保存，以及打包与发布入口检查职责、重复状态和调用方。保留现有系统浏览器产品形态。

## 已处理

- SettingsActions 在设置模块定义并复用，删除无调用的 getter 与 UI 重复接口；AI 参数直接引用平台契约。
- 保存状态集中维护修订号和书籍代次；重复保存合并，保存期间新编辑不被清除，旧书保存确认不清除新书状态。权限请求在等待存储前发起。
- 注释持久化不再为存储排序，replace 不再产生无人使用的排序结果；删除无调用的章节索引，渲染仍使用渲染器自己的缓存。
- 导入和编辑统一维护 ID 与 CFI 唯一性；外部注释显式校验字段，不再用类型断言把错误类型的正文或笔记带入 UI。
- 搜索读取当前注释，取消对注释存储及书籍标识的直接依赖。
- ZIP 配置改为实例选项，去掉跨模块全局配置副作用。
- 删除无调用的 Windows shell 转发入口；发布支持 Git 配置的 SSH 远端，并修复路径含单引号时读取版本失败。

## 保留依据

应用接口保留 TS，构建脚本继续使用 JS。OverlayDraw 泛型关联自定义绘制函数、选项和回调；保存状态负责真实异步时序，不按文件行数判断是否应删除。MathJax 与代码高亮按内容加载，ZIP 是打开 EPUB 的必要依赖。安装器仍由平台工具生成，不为消除构建大小提示增加包装层。

## 验证

- 当前工作区 Node 全量测试 150 项通过，类型检查与 Vite 生产构建通过。
- 系统 Chrome 搜索验证通过：读取最新注释、删除后清空结果、缓存复用、结果上限、取消和销毁。
- 保存状态测试覆盖保存期间编辑、重复保存、切换书籍、取消、失败和重试；未把这些单元测试等同于浏览器文件选择器端到端验证。
- 真实 ZIP 读写测试验证正文保留、旧注释覆盖、mimetype 顺序和不压缩要求；注释测试覆盖外部字段及重复 ID/CFI 索引一致性。
- 发布测试仅使用临时本地 Git 仓库，覆盖配置 SSH URL、原子推送、失败回滚及脏工作树拒绝。
- diff --check 通过。MathJax 等大 chunk 提示仍存在。本轮未修改原生安装实现，未重新执行 Windows/macOS 安装测试。

以上是本轮代码审查及相关路径的验证记录，不是所有平台、所有输入的无缺陷证明。本轮不变更版本号，不创建发布 tag。
